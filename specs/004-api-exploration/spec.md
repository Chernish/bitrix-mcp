# Feature Specification: расширенная навигация по API ядра

**Created**: 2026-08-22
**Status**: Implemented

## Цель

Закрыть возможности исследования API, которые есть у внешнего Bitrix MCP,
но отсутствовали в локальном: списки модулей, классов, функций и компонентов,
зависимости, иерархию, константы, реализации интерфейсов, DataManager, общий поиск
событий, callable и usages, чтение документа по адресу.

## Функциональные требования

- FR-001: система MUST перечислять модули и возвращать версию каждого.
- FR-002: система MUST давать структуру, зависимости и счётчики API модуля.
- FR-003: система MUST индексировать namespaced и глобальные PHP-функции через AST.
- FR-004: система MUST извлекать константы классов и сохранять выражение значения без выполнения.
- FR-005: система MUST извлекать точки вызова AST-разбором; динамическая цель MUST быть помечена.
- FR-006: все списки MUST быть ограничены и страничны; усечение MUST быть явным.
- FR-007: каждый факт о коде MUST нести версию модуля и SM_VERSION.
- FR-008: документ MUST читаться порциями и возвращать структурированные version notes.
- FR-009: исходные PHP-файлы и тела функций MUST NOT выгружаться целиком.

## Критерии приёмки

- В реестре 23 MCP-инструмента.
- Индекс содержит functions, constants и usages.
- Контрактные тесты provenance, read-only, context budget и truncation охватывают все инструменты.
