# Implementation Plan

## Архитектура

1. Повысить schema version до 8.
2. Добавить `global_function`, `class_constant`, `usage_reference` с FK на module/file.
3. Извлекать новые факты визиторами nikic/php-parser после NameResolver.
4. Реализовать 13 узких MCP-инструментов поверх новых и существующих таблиц.
5. Пересобрать индекс и прогнать полный quality gate.

## Constitution Check

- I: все факты о коде читаются только из локального индекса.
- II: новые таблицы имеют NOT NULL FK на module; выдача несёт provenance.
- III: функции, константы и usages извлекаются AST-визиторами.
- IV: все списки страничны; PHP-исходники не возвращаются.
- V: таблицы привязаны к file и участвуют в cascade/incremental rebuild.
- VI: сервер остаётся readonly; AST-выражения не выполняются.

## Осознанное ограничение

Возможность внешнего MCP «вернуть полный код функции» не копируется: это прямо
противоречит Принципу IV. Эквивалентная навигация даёт сигнатуру, файл, строку и usages.
