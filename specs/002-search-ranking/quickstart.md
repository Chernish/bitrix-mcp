# Quickstart: проверка спеки 002

## Автоматическая приёмка

```bash
cd server
npm test
npm run typecheck
npm run build
```

Ожидается: все unit/contract тесты зелёные, включая независимый временный FTS5
индекс и контрольный набор из 20 запросов. При наличии корневого `index.sqlite`
контрактные проверки не должны уходить в skip.

## Проверяемые сценарии

1. `send mail event`: первый результат имеет максимальное покрытие токенов.
2. Запрос без полного совпадения всё равно возвращает частичные.
3. `d7 IO ORM`: все три токена сохранены.
4. `как правильно работать с ORM-сущностью?`: дефис и пунктуация не ломают MATCH.
5. `!!! -- ()`: структурированный `invalid_query`.
6. Два одинаковых запуска `access rights user`: идентичный порядок.
7. `limit=-100` не превращается в неограниченную выдачу.
8. Типовые ответы каждого MCP-инструмента не превышают 2000 символов.
9. Максимальные `limit=10` для кода и `limit=5` для документации также не
   превышают 2000 символов и помечают усечение.
