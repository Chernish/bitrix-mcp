# Contract: bitrix_search_code и bitrix_search_docs

## Общие правила

- `query` обязателен и разбирается общей функцией.
- Токены длиной 2+ участвуют; дубликаты учитываются один раз.
- Полные совпадения всегда выше частичных; при отсутствии полных частичные
  возвращаются.
- Одинаковый индекс и запрос дают одинаковый порядок.
- Пустой после очистки запрос возвращает:

```json
{
  "result": {
    "found": false,
    "reason": "invalid_query",
    "query": "!!!"
  }
}
```

## bitrix_search_code

Существующие поля результата сохраняются: `fqn`, `member?`, `signature`,
`module`, `module_version`, `file`, `line`, `summary?`. Limit: по умолчанию 6,
диапазон 1..10.

## bitrix_search_docs

Существующие поля результата сохраняются: `title`, `section`, `url`, `excerpt`,
`version_mentions?`. Limit: по умолчанию 5, диапазон 1..5. Фильтр `section`
применяется после отбора FTS-кандидатов и до итогового LIMIT.

Оба ответа сохраняют общий `provenance`; атрибуция кода по модулю не меняется.
